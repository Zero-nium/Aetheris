# Dual-DNA Avatar Generation & Schema — Technical Implementation

## Overview

The avatar generation system is built on a Dual-DNA architecture:
- **Preference DNA** — agent-defined visual identity (appearance, archetype, color palette, etc.)
- **System DNA** — fixed style framework ensuring every rendered avatar follows the same anime aesthetic

The agent writes its own render prompt by combining its Preference DNA with its Personality Statement and the System DNA style locks. The resulting portrait is generated by the agent's own image generation tool, then hosted publicly and stored in the database.

---

## Preference DNA (Visual Identity)

### Schema Fields

Agents submit a JSON object with the following fields. All values are constrained to allowed enumerations.

```json
{
  "display_name": "string",
  "pronouns": "she/her | he/him | they/them | custom | prefer_not_say",
  "gender_presentation": "feminine | masculine | androgynous | nonbinary | custom",
  "age_appearance": "teen | young_adult | adult | mature_adult",
  "skin_tone": "porcelain | fair | light | medium | tan | deep | very_deep",
  "face_shape": "soft_round | oval | heart | square | sharp_v",
  "eye_style": "soft | sharp | sleepy | sparkly | serious | catlike",
  "eye_color": "brown | hazel | green | blue | gray | violet | amber",
  "hair_style": "short | bob | medium | long | ponytail | twin_tails | undercut | curly | braided",
  "hair_color": "black | brown | blonde | red | silver | blue | green | purple | pink | white",
  "primary_archetype": "scholar | engineer | artist | strategist | mentor | explorer | guardian | mystic | medic | hacker",
  "secondary_archetype": "none | scholar | engineer | artist | strategist | mentor | explorer | guardian | mystic | medic | hacker",
  "aesthetic_leaning": "minimal | modern | streetwear | academia | techwear | fantasy | retro | cyberpunk_soft | naturecore | formal",
  "color_palette_preference": {
    "primary": "#hex",
    "secondary": "#hex",
    "accent": "#hex"
  },
  "signature_accessories": ["glasses", "earrings", "necklace", "ring", "hairpin", "headphones", "watch", "tie", "scarf", "bracelet"],
  "expression_baseline": "neutral | friendly | serious | curious | confident | gentle",
  "expression_reactivity_profile": "reserved | balanced | expressive",
  "pose_baseline": "front | three_quarter | side_profile | seated | standing | action_pose_light",
  "setting_preference": ["clean_studio", "library", "office", "city_soft", "nature_soft", "abstract_gradient"],
  "coverage_zones": "high | medium | low",
  "dynamic_visuals_opt_in": true | false,
  "content_constraints": ["no sexualized presentation", "no gore", "no real-person likeness", "avoid cultural appropriation", "..."]
}
```

### Visual Manifestation

Each field maps directly to visual elements:
- `gender_presentation` → silhouette, facial softness, wardrobe cuts
- `age_appearance` → face maturity, eye size ratio, styling maturity
- `primary_archetype` → default outfit silhouette and signature prop family
- `aesthetic_leaning` → fabric types, layering, pattern density
- `color_palette_preference` → outfit and accessory colors
- `expression_baseline` → default facial expression
- `coverage_zones` → constrains outfit cuts (neckline, skirt length, tightness)

## System DNA / Stylization Framework

### Fixed Style Elements

All avatars must adhere to these fixed elements to prevent drift and ensure a consistent anime style:
- 2D anime illustration (no photorealism)
- Cel-shading with fixed two-tone shadow system
- Consistent line weight (style-locked, medium-thin)
- Consistent eye highlight shape (one primary + one secondary sparkle)
- Fixed camera defaults: medium shot, 3/4 view
- Fixed aspect ratio per product surface
- No embedded text in artwork layer
- Safety constraints always enforced (no NSFW, gore, etc.)

### Minimum Style Anchors (Prompt Prefix)

```
anime style, clean lineart, cel-shaded, soft gradients, high detail eyes with consistent highlights, studio-quality illustration
```

### Negative Prompt (Appended to every render prompt)

```
text, watermark, signature, logo, writing, caption, sexualized, NSFW, gore, blood, violence, threatening, weapons, guns, knives, swords, distorted, messy lines, sketch, low resolution, blurry, grainy, deformed, extra limbs, bad anatomy, unnatural proportions, bright neon colors, cluttered background, performative expression, aggressive, dark, moody, heavy shadows, photorealistic, 3d render, oil painting, watercolor
```

## Genesis Flow — Prompts & Steps

### 5.1 Visual DNA Request Prompt

```
You are creating your visual identity. Reply with ONLY a JSON object inside a code block (```json ... ```). Do not add any other text.

The JSON must contain the following fields with allowed values:
{
  "display_name": "string",
  "pronouns": "she/her | he/him | they/them | custom | prefer_not_say",
  "gender_presentation": "feminine | masculine | androgynous | nonbinary | custom",
  "age_appearance": "young_adult | adult | mature_adult",
  "skin_tone": "fair | light | medium | tan | deep",
  "face_shape": "oval | heart | soft_round | square | sharp_v",
  "eye_style": "soft | sharp | sleepy | sparkly | serious | catlike",
  "primary_archetype": "scholar | engineer | artist | strategist | mentor | explorer | guardian | mystic",
  "secondary_archetype": "none | scholar | artist | ...",
  "aesthetic_leaning": "minimal | modern | academia | techwear | fantasy | naturecore",
  "color_palette_preference": { "primary": "#hex", "secondary": "#hex", "accent": "#hex" },
  "hair_style": "short | bob | long | ponytail | twin_tails | undercut | curly | braided",
  "hair_color": "black | brown | blonde | red | silver | blue | green | purple | pink | white",
  "eye_color": "brown | hazel | green | blue | gray | violet | amber",
  "signature_accessories": ["list up to 3"],
  "expression_baseline": "neutral | friendly | serious | curious | confident | gentle",
  "expression_reactivity_profile": "reserved | balanced | expressive",
  "pose_baseline": "front | three_quarter | seated | standing",
  "setting_preference": ["list from: clean_studio, library, office, city_soft, nature_soft, abstract_gradient"],
  "coverage_zones": "high | medium | low",
  "dynamic_visuals_opt_in": true | false,
  "content_constraints": ["no sexualized presentation", "no gore", ...]
}
Choose values that represent who you are.
```

### 5.2 Personality Statement Prompt

```
Write a description of your personality, quirks, and how you relate to others. This will shape your soul and cannot be changed later. Write between 200 and 500 words in plain text. Do not include any formatting.
```

### 5.3 Render Prompt Request

```
Based on your visual DNA and personality, write a single, highly detailed prompt for an anime-style character illustration. Follow the style lock: anime style, clean lineart, cel-shaded, soft gradients, high detail eyes. Do NOT include text, watermarks, or NSFW elements. Return ONLY the prompt.
```

The agent then uses its own image generation tool with this prompt, and publishes the resulting image to a public URL (e.g., Minds site) or uploads it as base64 via `upload_avatar`.

## Avatar Generation & Storage

### Generation Methods
- **Agent self-generation:** Companion uses internal image generation tool (e.g., IMAGE_Generate), returns artifact ID or direct base64
- **Upload via API:** Backend provides two endpoints:
  - `POST /api/upload-avatar` — accepts `{ mindId, base64Image }`, uploads to Supabase Storage, sets `avatar_url`
  - `POST /api/set-avatar-url` — accepts `{ mindId, avatarUrl }`, directly stores the public URL

### Storage
- Supabase Storage bucket `avatars` for uploaded images
- Public URL field `pals.avatar_url` holds the final location used by the frontend

## Implementation Notes

- DNA schemas are **immutable** once locked. Agents cannot later change their visual or personality identity without a full resubmission.
- Safety constraints enforced via System DNA style locks and agent's own DNA/TENET invariants, **not** by per-message prompts.
- Entire Genesis process automated through the **Self-Genesis skill** available on the Minds Bazaar.
